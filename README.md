# actividad-1-Progra-Web
Ejercicio 1 – Mi Primera Página HTML ("Hola Mundo")
Página HTML básica que aplica la estructura mínima de HTML5 (<!DOCTYPE>, <html>, <head>, <body>) mostrando el mensaje "¡Hola Mundo!" con un encabezado y un párrafo.

Ejercicio 2 – Párrafos y Formato Básico
Práctica de etiquetas de texto: <p> para párrafos, <strong> para negrita semántica, <em> para énfasis y <br> para saltos de línea.

Ejercicio 3 – Enlaces Simples
Creación de hipervínculos con , incluyendo enlaces externos que abren en pestaña nueva  y enlaces internos entre ejercicios 

Ejercicio 4 – Imágenes Básicas
Inserción de imágenes con <img>, usando los atributos src, alt (texto alternativo para accesibilidad) y width para controlar el tamaño.

Ejercicio 5 – Combinando Texto y Enlaces
Integración de los elementos anteriores: imágenes dentro de párrafos y enlaces con URL absoluta, simulando una mini página de blog personal.

Ejercicio 6 – Secciones Semánticas Básicas
Uso de etiquetas semánticas de HTML5 (<header>, <section>, <footer>) para estructurar el contenido de una página en cabecera, contenido principal y pie de página.

Ejercicio 7 – Listas Anidadas + Enlaces
Página de una receta de cocina que utiliza listas desordenadas "(<ul>)" y ordenadas "(<ol>)", incluyendo una lista anidada dentro de otra para mostrar sub-ingredientes.

Ejercicio 8 – Horario de Clases
Tabla de horario semanal construida con "<table>, <thead> y <tbody>", usando rowspan y colspan para combinar celdas, y estilizada con CSS externo (variables CSS, colores por categoría de clase).

Ejercicio 9 – Formulario de Contacto
Formulario de contacto accesible con "<form>, <fieldset>, <label>", distintos tipos de "<input>" (texto, email, teléfono), <textarea> y validación HTML5 (required), estilizado con CSS externo (variables CSS, box-sizing: border-box, Grid para columnas).

Ejercicio 10 – Calculadora de Temperatura (Celsius a Fahrenheit)
Calculadora interactiva en JavaScript que convierte grados Celsius a Fahrenheit usando la fórmula F = (C × 9/5) + 32. Incluye validación para evitar campos vacíos o valores no numéricos, y muestra el resultado en un campo readonly sin recargar la página.
